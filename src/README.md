# Source Code

The running prototype is the `secureschool` package. Start it from the repository root with `python run.py`.

These Unit 3 files remain as the original module sketches:

- `capture.py` — camera frame acquisition for a single test event
- `detection.py` — face detection and cropping
- `recognition.py` — embedding generation and template matching
- `access_control.py` — zone-permission check and access decision
- `alerts.py` — human-reviewed alert creation
- `dashboard.py` — MVC administrator interface
- `audit.py` — security-event logging without extra biometric payload
- `privacy.py` — encryption helpers, retention, and deletion procedures
